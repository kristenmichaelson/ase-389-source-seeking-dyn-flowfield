# Multi-Robot Source Seeking in Dynamical Flowfield
This is a coursework project from ASE 389: Modeling Multi-Agent Systems (Fall 2021) at the University of Texas at Austin. In the project, we formulate a distributed hybrid controller for solving online source seeking problem in a dynamical environment. To learn more about the work, visit [kristenmichaelson.github.io/ase-389-source-seeking-dyn-flowfield](https://kristenmichaelson.github.io/ase-389-source-seeking-dyn-flowfield/).
